The wall

The manual's cylinder removal starts with "the ignition key (1) must be in the key cylinder (2)," turned to RUN, to reach the retaining pin. With no key, the old cylinder can't come out the manual way. A key that fits the old lock solves that and may make the new cylinder unnecessary.

Chip or no chip

The manual says the Sentry Key Immobilizer System (SKIS) "is available as a factory-installed option on this model." So this truck may or may not have a chip system. A plain key cut by code answers that on the first start; see step 5 below.

Cheapest path: a key cut by code

One phone call and a cheap key may finish the whole job.

  1. Call a Dodge/Ram dealer with the VIN. Ask two things: can they pull the key code for this VIN, and does the build sheet show Sentry Key.

  2. Bring the title or registration and a photo ID. Dealers ask for proof of ownership before they cut a key to a VIN.

  3. Have them cut a plain metal key by code. It's the cheapest key they sell, and you'll know within a minute whether you need anything more.

  4. Unlock the driver door with it. The manual says unlocking the driver door with the key disarms the factory alarm, if the truck has one.

  5. Turn the key to ON and watch the security indicator in the cluster. On a SKIS truck it lights for about 3 seconds as a bulb test. Then start it.

    Keeps running: no immobilizer. You're done. The new cylinder isn't needed; return it unopened.

    Starts, then dies after about 2 seconds: the truck has SKIS. The manual says it disables the engine "after about two seconds of running" when the key isn't a valid Sentry Key. The dealer can program a chip key.

When the code won't work

If anyone ever replaced the ignition cylinder or door locks, the factory code won't match them. And some makers don't keep codes for older vehicles; whether Chrysler still has them for a 2005 is a question for the dealer.

Sentry Key on the 2005

From the 2005 manual's SKIS description.

How to tell if it has it

  1. Dealer build sheet. The definite answer, from the VIN.

  2. Security light at key-on. SKIS trucks light the security indicator for about 3 seconds when the ignition goes to ON. Needs a key that turns.

  3. Under the column shrouds. The module sits on the right side of the steering column, and its molded plastic antenna ring "circles the ignition lock cylinder like a halo." No ring, no SKIS.

  4. The key itself. A Sentry Key's transponder is molded into the head, under the rubber cap. You can't see it from outside, so a key's looks don't settle it.

If it has it

  1. The module holds up to 8 keys. New keys are programmed by the dealer with a scan tool.

  2. The free owner self-program (Customer Learn) needs at least two valid Sentry Keys already working. With none, it's the dealer, or a locksmith with the right scan tool.

  3. Get two keys programmed, not one, so a lost key never puts the truck back in this spot.

If the dealer can't pull a code

  1. A locksmith can usually make a key that fits the existing locks without the code, working from the door lock. Ask for that first; it keeps the original cylinder in service.

  2. If the old cylinder has to come out without a key, it has to be drilled or extracted. The shop manual doesn't cover that, so it's a locksmith job. Then the new Dorman cylinder goes in with its own two keys.

  3. A new cylinder comes with its own key code, so the door locks still won't match it. Have the locksmith cut a door key at the same visit.

Cylinder R&R, once a key turns

The 2005 manual's procedure. Every step assumes a key that turns to RUN.

Airbag warning, from the manual

Before steering column service, disconnect and isolate the battery negative cable, then wait two minutes for the airbag system capacitor to discharge.

Remove

  1. Disconnect the negative battery cable and wait two minutes.

  2. Remove the upper and lower covers (shrouds) from the steering column.

  3. Put the shifter in PARK.

  4. With the key in the cylinder, turn it to RUN. Press in the retaining pin on the side of the cylinder while you pull the cylinder out of the ignition switch.

Install

  1. With the key in the new cylinder, line the end of the cylinder up with the ignition switch and slide it into the housing.

  2. Push it in until it clicks.

  3. Refit the upper and lower shrouds.

  4. Reconnect the battery. On a SKIS truck, the key also has to be programmed before the engine will keep running.

The Dorman 924-709

Dorman lists it for the 2005 Ram 1500 5.7L. It comes coded with its own 2 keys, and Dorman's spec says "Key Programmable: No," so those keys have no chip.

Two walls before you buy a part

This truck has the Sentry Key Immobilizer System (SKIS), and the key is lost with no spare. That blocks the job in two places, both confirmed in the manual:

1. You can't pull the old cylinder the manual way. Removal starts with "the ignition key must be in the key cylinder," turned to RUN, to reach the retaining pin. No key that turns means that method is out.

2. A new key won't start it on its own. The engine stays disabled until the immobilizer module has learned the key's transponder. The no-tool self-learn needs two keys that already work. With none, programming needs a scan tool and the truck's PIN.

What this means in practice

For an all-keys-lost SKIS truck, an automotive locksmith is the realistic path: they open it, cut a key, pull the PIN, and program keys. That same visit may mean you don't need a new cylinder at all, since a key cut to the existing lock is cheaper than replacing it. Read The locksmith before ordering parts.

Getting in

The shop manual has no forced-entry procedure, so nothing below is an unlock trick. It's what the manual tells you about this door so you don't fight the truck or wreck a $200 part.

  1. This is a power-lock door. Each door has a lock motor and an ajar switch, plus a switch in the key cylinder. There is a mechanical lock knob and an outside key cylinder; the inside manual lock knob is the simplest thing to reach for.

  2. The alarm will not be armed against you. The manual states the theft system does not arm when the doors are locked mechanically, and that mechanical locking overrides the system. So a quiet entry through the lock knob is not going to set off the horn.

  3. Behind the door panel sit the window regulator, the lock actuator and its wiring, all along the lower edge where a pry tool goes. A slip there is what breaks a regulator or bends the lock rod, and the manual has no map of those rod positions for this truck.

  4. Best call: have the locksmith who is already handling the keys open it. They do it non-destructively in minutes with an air wedge and a long reach tool, and they are coming out anyway for the immobilizer.

Why not just force it

Even a clean break-in leaves you with a truck that opens but will not turn (no key to RUN) and will not start (no learned transponder). Entry on its own doesn't move the job forward; the locksmith trip does all three.

The immobilizer (SKIS)

Why a cut key isn't enough, straight from the manual's Antitheft description.

  1. A transponder lives in the head of the key. On every start the Sentry Key Immobilizer Module (SKIM) reads it over RF; if it isn't a valid, learned transponder, the PCM keeps the engine disabled. A blank cut to the locks will crank but not run.

  2. The module holds up to 8 keys and the factory programs 2. The two factory keys exist precisely so the owner can self-program more if one is lost.

  3. Self-program (Customer Learn) needs two keys that already start the truck. You have none, so that door is closed. Programming now takes a scan tool that does Chrysler SKIM plus the truck's 4-digit PIN, which is a dealer or a locksmith with the right gear.

  4. Replacing the SKIM or the PCM is worse, not better: both carry a rolling code and a new one forces a full initialization. Keep the original SKIM; it already holds the VIN and secret key.

If you ever get two working keys

With two already-valid keys in hand, the system can learn more keys with no scan tool, by cycling the ignition between them within the system's timing windows. It is not usable here because it needs those two keys to start from. Don't buy parts planning on it.

The locksmith visit

What to have ready and what to ask for, so one trip covers entry, keys and programming.

  1. Have the VIN and proof of ownership ready. An all-keys-lost job on an immobilizer vehicle needs the PIN, and a legitimate locksmith will ask you to show the truck is the owner's before they pull it.

  2. Ask whether they can originate a key to the existing lock. If the cylinder turns fine and is just keyless, a new key to it skips buying and swapping a cylinder entirely.

  3. Have them read the PIN (by key code or off the SKIM) and program the keys to the truck. Confirm the transponder is learned, not just a cut blank.

  4. Get two keys cut and programmed, not one. Two working keys is what puts the free self-learn back on the table and keeps you out of this exact spot next time.

When you actually need a new cylinder

Replace the ignition cylinder if it is seized, worn so a new key won't turn it cleanly, or if the lock had to be drilled to get in. If it still turns, a key cut to it is the cheaper fix. Decide this with the locksmith before ordering the part. A new cylinder still has to be programmed the same way; the lock and the transponder are separate problems.

Cylinder R&R, once a key turns

The manual's own removal and install. Every step below assumes a key that turns to RUN, so this is the stage after the locksmith, not before.

Gate

Step 4 cannot be done without a working key. There is no retaining-pin release without turning the cylinder to RUN. If you have no key, this is a drill-out, which the shop manual does not cover; leave it to the locksmith.

Remove

  1. Disconnect the negative battery cable.

  2. Remove the upper and lower covers (shrouds) from the steering column.

  3. Put the shifter in PARK.

  4. With the key in the cylinder, turn it to RUN. A retaining pin sits in the hole on the side of the cylinder. Press the pin in while you pull the cylinder out of the ignition switch.

Manual figure

The book's Fig. 12 "Key Cylinder" labels the three things you're working with: 1 key, 2 key lock cylinder, 3 retaining pin hole. The pin hole is on the side of the cylinder body near the key end.

Install

  1. With the key in the new cylinder, line the end of the cylinder up with the ignition switch and slide it in.

  2. Push it in until it clicks.

  3. Refit the upper and lower shrouds.

  4. Reconnect the battery. Then have the new key's transponder programmed (see The immobilizer) before you expect it to start.
